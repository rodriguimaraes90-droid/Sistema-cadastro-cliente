# Sistema de Cadastro

Projeto que eu fiz pra aprender Python e banco de dados.

Sistema de cadastro de clientes feito em Python com SQLite.

## O que o sistema faz

- 1 - Cadastrar cliente
- 2 - Listar clientes
- 3 - Buscar cliente pelo nome
- 4 - Sair
- 5 - Contar quantos clientes tem cadastrados
- 6 - Excluir cliente
- 7 - Atualizar telefone e cidade do cliente

## Tecnologias usadas

- Python
- SQLite3
- Pydroid 3 (testado no celular)

## Como rodar

1. Baixe o arquivo `Cadastro.py`
2. Rode no Pydroid 3 ou em qualquer Python
3. Escolha uma opção no menu e siga as instruções
